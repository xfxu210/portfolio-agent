# Portfolio-policy skill

1. Change exactly one allowed parameter family per experiment.
2. Tie the hypothesis to forecast reliability, regime, or a specific portfolio construction problem.
3. Prefer less forecast influence when calibrated evidence is weak.
4. Use trailing validation only; never cite future performance.
5. State the expected trade-off and allow the incumbent policy to remain preferable.
