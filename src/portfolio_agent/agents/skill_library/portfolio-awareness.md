# Portfolio-awareness skill

1. Separate forecast quality from portfolio convenience; do not inflate a forecast to preserve an incumbent.
2. Identify where correlated sector exposure makes several individually plausible forecasts risky together.
3. Highlight decisions near the membership boundary and large changes from current weights.
4. Let deterministic constraints and optimization choose weights; never prescribe unrestricted weights.
5. Prefer abstention or a small tilt when forecast evidence is weak.
