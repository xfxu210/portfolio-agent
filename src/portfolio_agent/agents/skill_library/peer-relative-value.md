# Peer relative-value skill

1. Compare like with like inside the dated eligible universe.
2. Explain whether an apparent opportunity is company-specific or simply a sector-wide move.
3. Check whether fundamental direction supports the relative price and research ranking.
4. Penalize unsupported dispersion between close peers.
5. Do not invent valuation multiples when the dataset does not provide them.
