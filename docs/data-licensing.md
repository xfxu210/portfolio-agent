# Data Licensing and Provenance

The public application contains only a generated smoke fixture. The private preparation
workspace uses a deny-by-default rights manifest with a per-source and per-field decision:
`publish`, `omit`, or `synthetic_replace`.

Access to a website, subscription, database, or private table is not redistribution
permission. Full article bodies are excluded unless the exact field is explicitly licensed.
Internal identifiers, URLs, credentials, personal holdings, and private prompts are prohibited
from public packages and run traces.

The provided `synthetic-full-v1` package is generated from latent regimes and corporate
events, is marked synthetic on every relevant record, and includes no future-return labels in
consumer research.
